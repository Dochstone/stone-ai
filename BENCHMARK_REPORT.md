## ТОП-5 КРИТИЧЕСКИХ ПРОБЛЕМ ДЛЯ ИСПРАВЛЕНИЯ

### 1. Service Worker отсутствует (404) — Приоритет: ВЫСОКИЙ
- `/sw.js` возвращает 404
- Без него manifest.json бесполезен для PWA
- Пользователи не смогут установить приложение и использовать оффлайн
- **Решение:** Создать SW с кэшированием статических ресурсов, добавить регистрацию в layout

### 2. user-scalable=no блокирует масштабирование — Приоритет: ВЫСОКИЙ
- Viewport: `maximum-scale=1, user-scalable=no`
- Нарушает WCAG 1.4.4 (Resize Text)
- Google PageSpeed Insights снижает оценку доступности
- **Решение:** Убрать `maximum-scale=1` и `user-scalable=no` из viewport

### 3. Нет WebP/AVIF оптимизации изображений — Приоритет: СРЕДНИЙ
- 37 изображений без явного использования современных форматов
- WebP экономит 25-35% трафика, AVIF — до 50%
- **Решение:** Использовать Next.js `<Image>` с автоматической оптимизацией или настроить sharp

### 4. CSP содержит unsafe-inline/unsafe-eval — Приоритет: СРЕДНИЙ
- Позволяет потенциальные XSS-атаки
- **Решение:** Использовать nonce-based CSP (Next.js 13+ поддерживает nonce через middleware)

### 5. Только 3 страницы моделей в sitemap из 65+ — Приоритет: СРЕДНИЙ
- gpt-4o-mini, claude-haiku-4.5, gemini-2.0-flash — только 3 модели имеют отдельные страницы
- Потеря SEO-трафика по запросам типа "GPT-5 онлайн", "Claude Opus бесплатно"
- **Решение:** Создать страницы для всех ключевых моделей и добавить в sitemap

## Рекомендации по приоритету

| Приоритет | Задача | Влияние | Сложность |
|-----------|--------|---------|-----------|
| P0 | Добавить Service Worker | PWA-установка, оффлайн | Средняя |
| P0 | Убрать user-scalable=no | a11y, PageSpeed оценка | Низкая |
| P1 | Создать страницы для всех моделей | SEO-трафик по 60+ запросам | Высокая |
| P1 | Добавить WebP/AVIF для изображений | Скорость загрузки на мобильных | Средняя |
| P2 | Перейти на nonce-based CSP | Безопасность | Средняя |
| P2 | Добавить HSTS preload | Включение в preload-лист браузеров | Низкая |
| P2 | Добавить skip-navigation ссылку | a11y | Низкая |
| P3 | Добавить BreadcrumbList schema | SEO rich snippets | Низкая |
| P3 | Оптимизировать HTML размер (186 КБ) | Скорость на 3G | Средняя |
| P3 | Добавить hreflang (если планируется EN) | Международное SEO | Низкая |
