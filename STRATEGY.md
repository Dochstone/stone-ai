## Миссия

Stone AI — единая точка доступа ко всем мировым AI-моделям для русскоязычной аудитории. Без VPN, без десятков регистраций, без блокировок. Прямо в Telegram и на веб-сайте.

## Текущее состояние

### Что есть
- **Telegram Mini App** (React + Vite + Zustand)
  - 6 экранов: Home, Chat, Plans, Profile, FAQ, ModelDetail
  - 11 моделей (6 Lite бесплатных + 5 Premium за кредиты)
  - Стриминг ответов с Markdown-рендерингом
  - История чатов per-model в localStorage
  - 3 анимированные палитры (Matrix, Ocean, Sunset)
  - i18n на 3 языка (RU/EN/ZH)
  - BYOK (Bring Your Own Key) через OpenRouter
  - Оплата: Telegram Stars + карты (скоро)
  - VIP-система ($10,000+ = скидка на кредиты)
- **Backend** (FastAPI + PostgreSQL)
  - AI-роутер через OpenRouter
  - Кредитная система с атомарными списаниями
  - Rate limiter (Lite: 20/день, Premium: по кредитам)
  - BYOK endpoint (сохранение/удаление ключей)
  - Telegram Bot + payments handler
- **Инфраструктура**: Docker, Railway/Vercel, Яндекс.Метрика

### Чего не хватает (по результатам анализа конкурентов)
- ❌ Веб-сайт (SEO, органика, точка входа)
- ❌ Генерация изображений
- ❌ Загрузка файлов в чат (multimodal)
- ❌ API-документация для разработчиков
- ❌ Партнёрская программа
- ❌ Блог / контент-маркетинг
- ❌ Отзывы пользователей
- ❌ Юридические документы (оферта, privacy)

## Конкурентный анализ

### ishushka.com — AI-платформа
**Сильные стороны (взять себе):**
- Генерация изображений в чате с выбором aspect ratio
- 60+ моделей с фильтрацией по провайдеру и context length
- Интерактивная API-документация (api.ishushka.com)
- Партнёрская программа (/Partners)
- Загрузка файлов в чат с превью

**Слабые стороны (наши преимущества):**
- Нет BYOK — пользователи привязаны к ценам платформы
- Нет нативной Telegram-интеграции (haptic, Stars)
- Нет кастомизации интерфейса (только light/dark)
- Нет VIP-системы для крупных клиентов

### xab-store.ru — Маркетплейс цифровых товаров
**Сильные стороны (взять себе):**
- Блог с SEO-контентом
- Модерируемые отзывы с emoji
- Публичная оферта из 9 разделов
- Баннерная система монетизации

**Слабые стороны (наши преимущества):**
- PHP-бэкенд без SPA (медленная навигация)
- Нет мультиязычности
- Нет тёмной темы
- Нет чата с AI
- Нет API-документации

### chatbotai.co — Глобальная AI-платформа (Freemium)
**Компания**: Deep Flow Software Services - FZCO (ОАЭ)
**Заявляют**: 50M+ пользователей, 100k+ рейтингов
**Модель**: Freemium (бесплатно с рекламой → Premium подписка без рекламы)

**Сильные стороны (взять себе):**
- AI-инструменты как отдельные продукты: Search Engine, Image Generator, Link Analyzer, Chat PDF, YouTube Analyzer — каждый = отдельная SEO-точка входа
- "Trusted by individuals at" + логотипы (Intel, Netflix, MIT, Stanford) — социальное доказательство
- Секция безопасности на лендинге: SSL, GDPR, ISO — повышает доверие enterprise-клиентов
- Freemium с рекламой → Premium без рекламы = двойная монетизация
- Богатый signup-flow: отзывы + рейтинги + логотипы платформ прямо на странице регистрации
- WhatsApp интеграция — доступ за пределами одного мессенджера
- FAQ заточен под SEO long-tail запросы ("Can AI help me design tattoo ideas?")
- 4 юридических документа: Terms, Privacy, Community Guidelines, Refund Policy

**Слабые стороны (наши преимущества):**
- Нет BYOK — привязка к их ценам
- Нет кредитной системы pay-as-you-go — только подписка (менее гибко)
- Нет Telegram-интеграции (только Web + iOS + Android)
- Нет кастомизации интерфейса (без палитр/тем)
- Закрытая экосистема — пользователь не может подключить свой ключ

**Ключевой вывод для Stone AI:**
Chatbotai.co продаёт не "чат с AI", а набор специализированных AI-инструментов. Каждый инструмент — отдельный продукт с отдельным лендингом и SEO. Stone AI должен использовать тот же подход на сайте: не "один чат", а "6 инструментов" (AI Chat, Image Generator, PDF Analyzer, Web Search, Code Assistant, Translation Tool).

### Уникальные преимущества Stone AI
1. **BYOK** — ни один конкурент не предлагает подключение своего ключа
2. **Telegram-нативность** — haptic feedback, Stars оплата, WebApp API
3. **3 палитры** — Matrix Rain, Ocean, Sunset (премиум-эстетика)
4. **VIP-система** — скидки для крупных клиентов ($10,000+)
5. **Per-model history** — история чатов сохраняется отдельно по каждой модели

## Финансовая модель v2 (обновлена 16.03.2026)

> **Ключевые изменения**: переход с фиксированных кредитов на per-token billing (как ishushka), снижение free лимита до 10, реклама в Free, DeepSeek → платный, расширение до 50 моделей.

### НОВОЕ ценообразование

| Параметр | Было | Стало |
|----------|------|-------|
| Free-лимит | 20 req/день | **10 req/день** |
| Бонус за рекламу | Нет | **+5 req за просмотр рекламы** |
| Реклама в Free | Нет | **Да (баннеры + rewarded ads)** |
| Биллинг Premium | Фикс кредиты/запрос | **Per-token ($X за 1М токенов)** |
| DeepSeek R1 | Free (Lite) | **Платный (Premium)** |
| Количество моделей | 11 | **50+** |
| Lite-моделей (бесплатных) | 6 | **5** (DeepSeek убран) |

### Новая структура тарифов

#### Free Tier (10 + 5 запросов/день)
- 5 Lite-моделей: GPT-4o mini, Claude Haiku, Gemini Flash, Llama 4, Mistral Large
- 10 запросов бесплатно / день
- +5 запросов за просмотр рекламы (rewarded video/interstitial)
- Баннерная реклама в интерфейсе
- max_tokens: 2048 на ответ

#### Paid Tier (per-token, пополнение баланса в $)
- Все 50+ моделей (Lite + Premium)
- Оплата по реальному расходу токенов
- Наценка: **+300% над OpenRouter (x4)** (как у ishushka, но ниже по дешёвым моделям)
- Без рекламы
- max_tokens: 8192 на ответ
- Минимальное пополнение: $1
- Оплата: **4 метода** — Telegram Stars / TON Connect / Lava.ru (карты, СБП) / Heleket (USDT, BTC, ETH)

### Отображение цен для пользователя

**Снаружи**: одна цена за 1М токенов (средневзвешенная, как у ishushka)
**Внутри** (по клику): детали input/output per 1M
**Под капотом**: списание точное per-token (input x input_price + output x output_price)

**Формула средневзвешенной**: `цена_1М = (input_price × 0.4) + (output_price × 0.6)`
*(40/60 — типичный чат: вопрос короче ответа)*
