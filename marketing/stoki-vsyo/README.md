# «Стоки Всё» — продакшен-пакет для VK Shorts

## Что в папке

| Файл | Описание |
|------|----------|
| `01_PROMPTS_IMAGES.md` | 12 промптов для AI-картинок (Flux + GPT-5 Image) |
| `02_PROMPTS_VIDEO.md` | 5 промптов для AI-видео (Kling 3.0 + Sora 2) |
| `03_SUBTITLES.md` | Посекундные субтитры с размерами и цветами |
| `04_SUBTITLES.srt` | SRT файл для импорта в монтажную программу |
| `05_VK_DESCRIPTION.md` | Описание, хэштеги, UTM-ссылки для публикации |
| `06_VOICEOVER_SCRIPT.md` | Голосовой скрипт с подсказками по интонации |
| `07_MONTAGE_GUIDE.md` | Монтажный лист посекундно + цвет + звук + эффекты |

## Порядок работы

1. **Генерация контента** (30 мин)
   - Открой stoneai.ru/webchat
   - Сгенерируй 12 картинок по промптам из `01_PROMPTS_IMAGES.md`
   - Сгенерируй 5 видео по промптам из `02_PROMPTS_VIDEO.md`
   - Скачай 6 убогих стоков с Unsplash/Pexels

2. **Запись голоса** (15 мин)
   - Прочитай скрипт из `06_VOICEOVER_SCRIPT.md`
   - Запиши 3-4 дубля, выбери лучший

3. **Монтаж** (1-2 часа)
   - Следуй монтажному листу `07_MONTAGE_GUIDE.md`
   - Импортируй субтитры из `04_SUBTITLES.srt`
   - Главное: транзиция на 0:08 и пауза на 0:35

4. **Публикация**
   - Скопируй описание из `05_VK_DESCRIPTION.md`
   - Добавь UTM-ссылку

## Бюджет

Подписка Stone AI Mini (390₽/мес) или Max (890₽/мес) — все генерации включены.
