## Отличия от «Стоки всё»

| | Стоки всё | Один промпт |
|---|-----------|-------------|
| Голос | Да | Нет (музыка) |
| Переходы | Резкие каты | Dissolve (как Google) |
| Структура | 4 акта + продажа | Промпт → результаты → wow → CTA |
| Ритм | Средний | Быстрый (6 кадров за 12с) |
| Стиль | Контраст стоки/AI | Premium презентация |
| Длительность | 42с | 38с |

## Порядок работы

1. Сгенерируй 6 картинок по промптам из `01`
2. Сгенерируй 1 видео по промпту из `02` (2-3 дубля)
3. Запиши скринкаст печати промпта в Stone AI (OBS, 60fps)
4. Найди cinematic buildup трек (Epidemic Sound / Pixabay)
5. Монтируй по `04_MONTAGE_GUIDE.md`
6. Импортируй `03_SUBTITLES.srt`
7. Опубликуй с описанием из `05`
