# ЗАДАЧА: Интеграция AI Video Editing APIs в Stone AI

## Контекст

Stone AI (stoneai.ru) — агрегатор 65+ нейросетей. Веб-чат + Telegram-бот (@drifttt55bot).
Пользователи уже генерируют картинки и видео. Нужно добавить возможность МОНТАЖА и РЕДАКТИРОВАНИЯ видео прямо на сайте.

## Что нужно сделать

Интегрировать 5 API для работы с видео. Каждый API — отдельный модуль, который подключается к существующему интерфейсу Stone AI.

## ШАГ 1: Shotstack API — Автомонтаж

**Документация:** https://shotstack.io/docs/api/
**Что делает:** Собирает видео из клипов, картинок, текста и аудио через JSON-описание таймлайна
**Цена:** ~$0.04/сек видео

### Задача:

Создать раздел «Монтаж» / «Video Editor» в интерфейсе Stone AI, где пользователь может:

1. **Выбрать материалы** — загрузить или выбрать из ранее сгенерированных картинок/видео в Stone AI
2. **Настроить параметры:**
   - Порядок клипов (drag & drop)
   - Длительность каждого клипа (от 0.5 до 10 сек)
   - Переходы между клипами (cut, dissolve, fade)
   - Добавить текст/субтитры поверх (позиция, шрифт, размер, цвет)
   - Добавить аудио (загрузить или выбрать из библиотеки)
   - Ken Burns эффект на статичных картинках (zoom-in, zoom-out, pan)
   - Формат: 9:16 (Shorts/VK Clips), 16:9 (YouTube), 1:1 (Instagram)
3. **Отправить на рендер** через Shotstack API
4. **Показать прогресс** рендеринга (polling статуса)
5. **Дать скачать** готовое видео

### Бэкенд:

```
POST /api/video/montage
Body: {
  clips: [
    { type: "image", url: "...", duration: 2, kenBurns: "zoom-in" },
    { type: "video", url: "...", trim: { start: 0, end: 5 } },
    ...
  ],
  transitions: "cut" | "dissolve" | "fade",
  audio: { url: "...", volume: 0.7 },
  subtitles: [
    { text: "...", start: 0, end: 3, position: "bottom", style: "..." }
  ],
  format: "9:16" | "16:9" | "1:1",
  resolution: "1080p"
}
Response: { jobId: "...", status: "queued" }

GET /api/video/montage/:jobId
Response: { status: "rendering" | "done" | "failed", progress: 75, url: "..." }
```

### Логика:

1. Принять параметры от фронтенда
2. Сформировать Shotstack JSON (Edit + Output)
3. Отправить POST на https://api.shotstack.io/edit/v1/render
4. Вернуть jobId
5. Фронтенд пуллит GET /api/video/montage/:jobId каждые 3 сек
6. Когда готово — вернуть URL на скачивание

### ENV:

```
SHOTSTACK_API_KEY=xxx
SHOTSTACK_ENV=v1  # stage для тестов, v1 для прода
```

## ШАГ 2: JSON2Video API — Альтернативный автомонтаж

**Документация:** https://json2video.com/docs/api/
**Что делает:** То же что Shotstack, но проще и дешевле ($0.02/сек)
**Зачем два:** Shotstack — основной (больше функций), JSON2Video — фоллбэк и бюджетный вариант для пользователей

### Задача:

Добавить JSON2Video как альтернативный движок в том же разделе «Монтаж». Пользователь выбирает движок: Shotstack (больше эффектов) или JSON2Video (дешевле).

### Бэкенд:

Тот же эндпоинт /api/video/montage, но с параметром engine:

```
POST /api/video/montage
Body: {
  engine: "shotstack" | "json2video",
  clips: [...],
  ...
}
```

Адаптер конвертирует наш формат в формат JSON2Video API.

### ENV:

```
JSON2VIDEO_API_KEY=xxx
```

## ШАГ 3: Runway Gen-4 API — AI-редактирование

**Документация:** https://docs.runwayml.com/
**Что делает:** AI-редактирование через промпт: убрать объект, сменить стиль, изменить освещение, расширить сцену
**Цена:** ~$0.05/сек

### Задача:

Добавить Runway Gen-4 как модель в существующий интерфейс Stone AI (как добавлены Sora, Veo, Kling). Пользователь:

1. Загружает видео (или берёт ранее сгенерированное)
2. Пишет промпт: «Сделай ночь», «Убери дерево справа», «Добавь дым»
3. Получает отредактированное видео

### Бэкенд:

Подключить как новую модель в существующую систему моделей Stone AI. Эндпоинт:

```
POST /api/video/edit
Body: {
  model: "runway-gen4",
  videoUrl: "...",
  prompt: "Change lighting to golden hour, add volumetric fog",
  duration: 10
}
Response: { jobId: "...", status: "processing" }
```

### ENV:

```
RUNWAY_API_KEY=xxx
RUNWAY_API_VERSION=2024-11-06
```

## ШАГ 4: Luma Reframe API — Умный рефрейминг

**Документация:** https://docs.lumalabs.ai/
**Что делает:** Автоматический рефрейминг видео: 16:9 → 9:16 (и наоборот) с сохранением ключевых субъектов
**Зачем:** Пользователь сгенерировал видео 16:9 → одна кнопка → получает 9:16 для VK Clips/Shorts

### Задача:

Добавить кнопку «Адаптировать для Shorts» рядом с каждым сгенерированным видео. При клике:

1. Отправить видео в Luma Reframe API
2. Показать прогресс
3. Вернуть видео в формате 9:16

### Бэкенд:

```
POST /api/video/reframe
Body: {
  videoUrl: "...",
  targetAspectRatio: "9:16" | "16:9" | "1:1"
}
Response: { jobId: "...", status: "processing" }

GET /api/video/reframe/:jobId
Response: { status: "done", url: "..." }
```

### Фронтенд:

Кнопка «9:16» / «16:9» / «1:1» рядом с каждым видео в интерфейсе. Модальное окно с прогрессом.

### ENV:

```
LUMA_API_KEY=xxx
```

## ШАГ 5: Grok Imagine API (xAI) — Редактирование + генерация

**Документация:** https://docs.x.ai/docs/guides/imagine
**Что делает:** Генерация и редактирование картинок/видео через промпт, смена стиля, нативный звук
**Цена:** ~$0.03/сек

### Задача:

Добавить Grok Imagine как модель в Stone AI:

1. **Генерация видео** — text-to-video и image-to-video (как Sora/Veo)
2. **Редактирование видео** — загрузить видео + промпт → отредактированное видео
3. **Генерация картинок** — text-to-image (как GPT-5 Image)

### Бэкенд:

Подключить в существующую систему моделей. SDK:

```python
import xai_sdk
client = xai_sdk.Client(api_key=GROK_API_KEY)

# Генерация видео
response = client.video.generate(
    prompt="...",
    model="grok-imagine-video",
    duration=10,
    aspect_ratio="9:16",
    resolution="720p"
)

# Редактирование
response = client.video.edit(
    video_url="...",
    prompt="Change the sky to sunset",
    model="grok-imagine-video"
)
```

### ENV:

```
GROK_API_KEY=xxx
```

## ШАГ 6: Общие требования

### Биллинг

Каждый API-вызов стоит денег. Нужно:

1. Считать стоимость каждого вызова (по длительности видео × цена/сек)
2. Списывать с баланса пользователя
3. Показывать предварительную стоимость перед рендером
4. Логировать все вызовы (пользователь, модель, длительность, стоимость, статус)

### Очередь

Рендеринг видео — асинхронный процесс. Нужна очередь задач:

1. Принять задачу → поставить в очередь
2. Обработать → отправить в API
3. Пуллить статус → обновлять в БД
4. Когда готово → уведомить пользователя (вебсокет или polling)
5. Хранить результат 24 часа, потом удалять (или переносить в хранилище пользователя)

### Ошибки

1. Если API вернул ошибку → не списывать деньги
2. Retry логика: 3 попытки с exponential backoff
3. Если API недоступен → показать пользователю альтернативу (Shotstack ↔ JSON2Video)
4. Таймаут: 5 минут на рендер, потом уведомить пользователя

### Безопасность

1. API ключи только на бэкенде, никогда на фронтенде
2. Rate limiting: максимум 5 рендеров одновременно на пользователя
3. Максимальный размер загружаемого файла: 500MB
4. Валидация форматов: только mp4, mov, png, jpg, webp, mp3, wav

### UI/UX

1. Новый раздел в навигации: «Монтаж» (или «Video Editor»)
2. Drag & drop загрузка материалов
3. Визуальный таймлайн (упрощённый)
4. Превью перед рендером (опционально — статичная превью-сборка)
5. Прогресс рендеринга с процентами
6. Кнопка скачать + кнопка «Поделиться»
7. Адаптивный дизайн (работает на мобильных)

## Приоритет интеграции

1. **Первым:** Shotstack (основной монтаж) — это киллер-фича
2. **Вторым:** Grok Imagine (генерация + редактирование) — расширяет возможности
3. **Третьим:** Luma Reframe (рефрейминг) — простой, быстро интегрируется
4. **Четвёртым:** JSON2Video (бюджетный монтаж) — фоллбэк для Shotstack
5. **Пятым:** Runway Gen-4 (AI-редактирование) — продвинутая фича
